# TrackCOOP pre-push integration audit — 2026-11-05

All pending tracked/untracked project changes were backed up locally before staging. Environment files, credentials, runtime uploads, caches, ignored local tools and Windows desktop.ini were excluded. No force push, database migration or manual deployment is part of this integration.

## Integration

The initial local branch had 29 unique commits and origin/main had eight. Pending local refinements were committed first. Origin/main was merged without rewriting either history. Its production deployment safeguards and sequential deployment command are retained. Three conflicts in the map component, stylesheet and browser test were reviewed against both implementations: the common boundary dataset/join/local geometry route were identical; the newer local implementation additionally supports custom comboboxes, analytics details, legend selection, robust keyboard activation and fullscreen/fallback handling. That newer implementation and its matching tests were retained. No financial or membership calculation was changed to resolve a merge.

The audit found a stale frontend rental test still expecting a 20% discount. Its expected values were corrected to the existing approved 5% rule; runtime pricing was untouched. Historical public-photo tests were updated to the already implemented saved-placement/image-only-viewer contract. The member-analytics cross-page test now verifies the current independent financial-analytics endpoint instead of the retired financial-dashboard contract. The report date test closes the picker through its own trigger instead of clicking content covered by the popup. Browser testing also found a real lightbox backdrop-dismissal defect; pointer dismissal now closes only when the background itself is targeted, preserving image/control interactions, Escape and focus return.

## Automation and remaining limits

Production Verpex workflows remain manual and require an exact commit SHA/request ID. A push runs GitHub CI; the existing successful-CI staging workflows may run automatically. This audit does not dispatch production deployment. GitHub's actual run result must be checked separately; successful local checks are not a claim of a completed hosted CI run.

The existing lint debt and zero-test records glob remain explicit known limits. The excluded Windows desktop.ini remains local. Local design-skill folders remain ignored tools, not application payload. Original environment files and backups remain local.
